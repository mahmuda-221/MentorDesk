# MentorDesk

## Project Overview
MentorDesk is a proposed web application designed to help interns submit questions, receive responses from mentors, and track the progress of their questions.

## Objectives
- Allow interns to submit and manage questions.
- Enable mentors to review questions and provide responses.
- Track question status and follow-up comments.
- Provide dashboards and search/filter functionality.

## User Roles
- **Intern:** Submit questions and track progress.
- **Mentor:** Review questions, respond, and update status.
- **Administrator:** Proposed role; subject to supervisor approval.

## Proposed Technology Stack
- **Frontend:** React.js
- **Backend:** Node.js and Express.js
- **Database:** PostgreSQL

*The proposed technology stack is subject to supervisor approval.*

## Core Features
- User registration and login
- Question submission and tracking
- Mentor responses and status updates
- Follow-up comments
- Search and filtering
- Dashboard summaries
